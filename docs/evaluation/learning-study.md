# 真人学习研究协议与分析

当前只交付协议、空白 CSV 模板和分析工具，尚无真人学习数据，也没有实际学习提升结论。固定学生回答、工具通过率、反馈质量评分和模型轨迹属于行为或教学质量证据，不能代替真人前测、后测及保持测验。工具无法核实数据来源，只有研究者确认来自真实参与者的记录才能用于学习结果报告。

## 招募与研究控制

1. 研究开始前写明研究问题、目标学习者、纳入条件、招募渠道、计划人数、招募截止规则、教学时长、测验安排、评分标准和缺失处理规则。自愿招募，说明用途、数据保存期限和退出方式，取得知情同意；按所在机构要求完成适用的伦理流程。小规模便利样本只作探索描述，不能自动推广到所有学习者。
2. 每人仅参加一个平行组：`rule` 或 `agent`。两组学习目标、教材版本、知识点、练习内容与难度、教学时长、设备、教师帮助和测验条件应匹配；记录实际执行偏离。除教学策略外尽量控制条件，防止两组交换材料或先后体验两种策略。若开展实际实验，预先制定随机分组流程，在前测后执行并单独保存分配记录；不得把自行选择组别的观察研究称为随机实验。
3. 教学前独立完成前测，教学后独立完成后测。使用覆盖相同目标、题数、满分、评分规则与难度相当的等价卷；预先审题或试测，避免直接复用已讲解题目导致记忆效应。可把等价卷 A/B 的前后顺序在两组内平衡安排。测验不允许教练协助，尽可能由不知道分组的评分者按同一量表评分。
4. 预先固定即时后测时间、延迟测试间隔和允许窗口，所有参与者遵循同一安排；例如研究者可选定七天后的保持测验。延迟卷也应覆盖相同目标且满分相同，记录窗口内额外学习或辅导。未测或退出保留缺失，不能凭教学对话推测分数。
5. 使用随机生成的匿名 `participant_id`，每人一行，策略一经分配不跨组。若回访需要联系方式，联系表与分配日志分开加密或受限保存，不导入本 CSV。姓名、邮箱、学号、账号、原始聊天记录等个人数据不得进入公开仓库或公开报告。即便只有匿名 ID，逐人分数也应本地受限保存；公开前评估重新识别风险，只发布获准的汇总。
6. 另行收集学习者满意度、感知帮助和使用体验，注明量表、答复人数和缺失人数，不放入本 CSV，也不与客观分数合成“学习收益”。人工教学质量量表同样独立报告。

## CSV 契约

[空白模板](learning-study-template.csv) 只有表头，没有示例或伪造的学习者记录。每行对应一名真实学习者的一次前后测配对，`delayed_correct` 列可以整体省略。

| 列 | 要求 |
| --- | --- |
| `participant_id` | 非空匿名 ID，去除首尾空白后全文件唯一，区分大小写；排除行也不能重复 |
| `strategy` | 严格为 `rule` 或 `agent`，代表两个平行组 |
| `pre_correct` | 前测正确题数或预先约定的整数得分，0 到 `max_score` |
| `post_correct` | 后测整数得分，0 到 `max_score` |
| `max_score` | 大于 0 的整数，同一行前测、后测、延迟测验共用满分 |
| `delayed_correct` | 可选延迟测验整数得分，0 到 `max_score`；未测留空 |

分数接受整数字面量，拒绝 `true`、`False`、小数、科学计数法、NaN 和任意非数字字符串。0 是有效实测分数，不代表缺失。CSV 是 UTF-8（可带 BOM），列可调换顺序，单元格首尾空白会去除。未知或重复列名、行列数量不符、损坏的 CSV、缺失必需列、空 ID、非法策略、重复 ID 和超范围分数使整个分析失败，不产生部分成功报告。需要填写缺失值时保留空单元格及对应分隔符。

前测、后测或满分单元格缺失的行明确计入 `exclusions` 和 `excluded_n`，不参加任何均值或组间差计算；保留行号、匿名 ID、组别、缺失字段及原始已知分数。所有已填写的值先校验，不能把错误值藏进排除行。延迟分数空白不会排除一个完整的前后测配对；其原始值及标准化值均为 JSON `null`。若前后测不完整，即使有延迟分数，该行也不参加延迟均值。本工具没有补值流程。

空文件缺少表头，是错误；只有合法表头的模板是有效空研究：两组人数为 0，所有均值与组间差为 `null`，不会生成学习提升结论。完全空白的物理行由 CSV 读取器忽略，不算参与者。

## 本地运行与结果解释

在仓库根目录运行，只需 Python 3 标准库，不会调用模型或网络：

```sh
python3 backend/tutor_study.py docs/evaluation/learning-study-template.csv
```

分析已获授权的真实数据时，把输入及输出保存在公开仓库之外的受限目录，例如先准备好该目录，再运行：

```sh
python3 backend/tutor_study.py /private/study/learners.csv > /private/study/summary.json
```

命令成功时退出码为 0，标准输出是完整 JSON；数据、文件、编码或命令行参数错误时退出码为 2，标准错误输出 `{"error":"可读的错误原因"}`，标准输出为空，不打印堆栈。字段错误会注明行号和字段。脚本不能验证匿名化是否充分，请在导入前核对。也可在 Python 中导入 `analyze_csv(path)` 获取同样的字典；函数对错误抛出异常，由调用方处理。

结果字段如下：

- `total_n`、`included_n`、`excluded_n`：读取到的记录数、完整配对人数和排除数，满足总数等于纳入加排除。`exclusions` 可逐条复核，`groups` 也列出每组 `excluded_n`，应一并报告脱落情况与原因。
- `participants`：完整配对的逐人匿名 ID、策略、`raw` 原始整数分数，以及 `normalized` 的 `pre`、`post`、`gain`、`delayed`。标准化分数为原始分数除以该行满分，范围 0–1；`gain = (post_correct - pre_correct) / max_score`，范围 −1 到 1，保留负增益。它是分数比例的绝对变化，不是相对增长率或按提升空间归一化的增益。乘以 100 可转换为百分点变化。
- `groups.rule`、`groups.agent`：`n` 为完整前后测配对人数；`pre_mean`、`post_mean`、`gain_mean` 为该组标准化分数及逐人增益的算术均值，每人等权，不把题数合并后计算。`delayed_n` 为这些配对中实际有延迟分数的人数；`delayed_mean` 仅使用这些可用观测。延迟测验脱落者不能算成 0，也不能假定与完成者相同。
- `comparison.gain_difference_agent_minus_rule`：Agent 组平均增益减去规则组平均增益，只描述当前样本；任一组没有完整配对时为 `null`。正值或负值均不能推出策略造成提升或下降，不能声称统计显著。本 CLI 不做假设检验、置信区间、功效分析或因果估计；即使实际采用随机分组，也仍只输出这些描述统计。

标准化允许读取不同满分的记录，但不证明它们测量的是同一能力，也不能弥补不等价试卷。应在实际研究中统一测验蓝图与满分，并报告样本来源、分配方法、前测差异、缺失及脱落、等价卷依据和协议偏离。完整配对分析可能存在选择偏差；本工具的缺失处理不是意向治疗分析，也不消除混杂。当前没有可发布的真人研究结果，不能用单元测试中的合成解析样本或空模板宣称任何真实学习收益。

## 验证命令

```sh
python3 -m unittest discover -s backend/tests -p test_tutor_study.py -v
```

测试用临时 CSV 和真实 CLI 检查汇总、缺失处理、重复 ID、非法值、格式与友好错误；合成测试数据只验证程序行为，不是研究证据。
