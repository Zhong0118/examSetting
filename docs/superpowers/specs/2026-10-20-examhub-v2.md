# ExamHub V2：教材、证据与评测

用户已批准直接实现。V1 基线 d22a829；在 codex/examhub-v2 开发，不混入 V1 PR。仍为单进程 SQLite 工作台，不实现 V3 Agent。

## 产品与范围

- 新增教材库：上传 PDF、按物理页阅读原文件与提取文字、选择页范围、按范围生成题目。复用 pypdf（BSD）及 PDF.js（Apache-2.0），不自行实现解析器。
- 20 MiB / 200 页 / 全文 2M 字符限额；解析使用限时子进程，拒绝加密、损坏、无文字 PDF，部分无文字页显示警告，不声称有 OCR。页码始终为 PDF 物理页，从 1 开始，不等同印刷页码。每次出题最多 20 页、总文字 30000 字符，超限明确要求缩小范围，禁止静默截断。
- 文件、逐页文本与 SHA256 持久化；同用户同文件去重。教材私有，其他用户不能获取原 PDF 或全文。公开题集只分享被选择的引用摘录；出处卡片说明原 PDF 权限，原作者可打开原页。
- 编辑器可以从自己的教材页手工绑定逐字引文，不配置模型也能验证完整导入/溯源/质量检查流程。AI PDF 出题强制给出 page 与 source，引文经过统一 NFKC+空白折叠校验；后端填充可信元数据，模型不能自行宣称验证通过。
- 题目 citation 在题集、复制与作答快照里保存；实践答题前隐藏 citation 和 source，防止教材摘录直接泄露答案。提交后显示引用。历史不因源教材删除丢失引用快照，打开原文件时明确不可用。
- 质量检查：结构、唯一正确选项、解析、PDF 引文/页码一致性、精确及词面近似重复。报告是可解释规则检查，不等于事实正确性、语义去重或学习效果。
- 评测台：固定原创带缺陷标注测试集，比较 structural-v1 与 grounded-v2 两套检测规则，提供样本、逐项输出、precision/recall、数据集哈希及 JSON 导出；明确是检测器回归基准，不是模型效果榜。
- 另提供真实模型出题策略对比：同一教材同页同题量，依次运行 baseline（结构校验）和 grounded（引文验证+一次修复），保存两个 job 后建立报告，比较成功率、规则通过率、引用覆盖、耗时与调用次数。失败不从分母消失，不提供虚构成本、正确率或实时结果。调用用用户已配置模型，验收只用本地 HTTP 测试供应商。

## 数据与 API 契约

原有 API 不破坏；写请求 X-Requested-With / X-Expected-User 保护沿用。

Document = {id,title,filename,sha256,pageCount,textPageCount,createdAt,warnings:string[]}
DocumentPage = {page:number,text:string,charCount:number}
Citation = {documentId,documentTitle,documentHash,page:number,quote:string}
Question 新增 citation?:Citation|null；source 必须与 quote 规范化后一致。禁止伪造页码/哈希；fork 可以保留已有 citation，但不得借此读原 PDF。

- GET /api/documents -> {documents:Document[]}
- POST /api/documents multipart file -> {document:Document,duplicate:boolean}，201 或重复200
- GET /api/documents/:id -> {document:Document,pages:DocumentPage[]}
- GET /api/documents/:id/file -> application/pdf，owner only
- DELETE /api/documents/:id -> {ok:true}；已有 citation 快照保留，未来打开返回404
- 内部 documents.selection(document_id,user_id,start_page,end_page) -> {document:Document,pages:[DocumentPage],source:string}，使用 get_db app context；source 为各页原文拼接（模型 prompt 另带页号结构）。
- 内部 documents.canonical_citation(value, source, user_id, existing=[]) -> Citation；从 owner PDF 验证重建，或完全匹配 existing citation 时允许保留不可访问/已删除的来源，不允许改变其内容。
- POST /api/ai/jobs 增加可选 {documentId,startPage,endPage,strategy:'baseline'|'grounded',requestId?:string}；PDF 模式 source 从库读取，仍支持旧文本模式；默认 grounded。评测在请求前保存每轮 requestId（16–100 位字母数字或 _-）；同用户同编号和输入重发返回原任务，不重复调用，不同输入返回409。
- Job 增加 metadata:{strategy,documentId:null|string,pages:number[],sourceHash,count,model,provider,promptVersion,title,topic,elapsedMs:number|null,modelCalls,metricsFinalized:boolean} 和 quality:QualityReport|null；数据库增列采用兼容迁移。
- POST /api/quality/check {questions:Question[]} -> {report:QualityReport}；输入上限100，服务端校验引用来源，不仅相信客户端引用。
- GET /api/sets/:id/quality -> {report:QualityReport,version:number}，owner only，直接评估当前题集；前端只有版本匹配时才展示报告
- QualityReport = {ruleVersion,total,passed,passRate,citationCoverage,duplicatePairs:[{left,right,similarity}],items:[{questionId,passed,checks:[{code,status:'pass'|'fail'|'warn',message}]}],limits:string[]}
- 内部 quality.evaluate_questions(questions,pages=None) -> QualityReport，pages 若传入为 {pageNumber:text}。未传入时引文仅为快照级检查，必须声明限制；路由负责按真实 document ID/hash/page 校验。
- POST /api/evaluations/benchmark -> {report:BenchmarkReport}，无模型费用，固定集自动运行并返回实际计算值
- BenchmarkReport = {kind:'detector-benchmark',datasetId,datasetHash,ruleVersion,createdAt,sampleCount,strategies:[{name,precision,recall,tp,fp,fn,tn,samples:[{id,label,predicted,issues:string[],description,questions,pages}]}],limitations:string[]}
- POST /api/evaluations {jobIds:[string,string]} -> {evaluation:Evaluation}；必须本用户且终态、metricsFinalized 不为 false，教材/hash/页/数量/模型/供应商/提示配置相同，一 baseline 一 grounded；按两个 job ID 幂等保存快照，响应丢失后重试返回原快照。取消后需等待在途调用计时收尾，重启导致耗时未知时保存 null，不记为 0。
- GET /api/evaluations -> {evaluations:Evaluation[]}
- GET /api/evaluations/:id -> {evaluation:Evaluation}
- Evaluation = {id,createdAt,kind:'generation-comparison',documentTitle,sourceHash,pages:number[],count,model,runs:[{jobId,strategy,status,error,elapsedMs,modelCalls,questionCount,passRate,citationCoverage}],limitations:string[]}

## 前端

延续现有风格、动效、响应式和账户隔离。新增 /documents 与 /documents/:id?page=；教材页双栏（原页 canvas + 提取文字）手机上下；引用文字面板高亮，不假装精确 PDF 坐标高亮。可选页码输入，跳转 /sets/new?documentId=&startPage=&endPage=。
编辑器 AI 面板支持文本/PDF 资料；手工每题绑定/移除来源；详情和结果使用复用 CitationCard，在当前账户可读时打开教材页，其他情况保留摘录并解释限制。题集质量卡片显示逐项问题。新增 /evaluations：固定集检测器基准和真实生成对比两个明确区域，历史可回看及导出 JSON。不默认调用模型。

## 验收

真实双页原创 PDF 上传、读取原页、手工引用第2页、保存题集、质量报告、跨会话不得读教材、练习前不泄露引用、作答后仍可溯源、fork/历史/教材删除引用不丢失。模拟模型通过真实 HTTP 协议完成 PDF 生成和对比；错误页码/引用、损坏/加密/扫描版、重启任务、权限、超限都有回归。浏览器桌面/390px手机操作并截图检查；全量测试与构建通过，独立审查。
