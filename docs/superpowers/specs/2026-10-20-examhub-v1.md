# ExamHub 工作台首个可运行版本

用户已批准方向并授权完成规格后直接开发。本文定义本轮完整交付范围，后续教学 Agent 与 PDF 解析作为独立版本，不能在界面中伪装已实现。

## 产品与界面

中文个人学习工作台、我的题库、发现题集、学习记录、题集详情、编辑器、专注练习、模型设置。首版示例围绕计算机网络、数据库、操作系统，明确原创示例，不制造用户、热度、学习数据。首页以一张有编辑感的蓝色继续学习面板和真实题集列表为核心，左侧窄导航，桌面右栏展示练习建议，手机单栏。白 #ffffff、背景 #f6f8fc、文字 #172033、次文字 #738096、蓝 #3563e9、边框 #e6ebf3。系统中文字体，不再加载旧的大字体。使用开源 SVG 图标。

所有视图、弹层有进入退出过渡；按钮有按压与焦点反馈；支持 reduced-motion。可操作控件必须实际工作，错误、空数据、保存中状态明确。

## 本轮闭环

- 首次访问自动建立独立访客身份，刷新保留；可注册绑定账户与登录，不预置共享 demo 身份。
- 真实后端存储题集、版本、收藏和作答。SQLite 用于单机首版，公开规模化部署的 PostgreSQL 迁移不是本轮已交付能力。
- 手工创建与修改题集，单选和简答；题目含题干、选项、参考答案、解释和可选文本出处。
- private 私有、unlisted 仅链接访问、public 广场发现；用户只能编辑自己的题集。
- 查看、搜索、收藏、复制改编、复制分享链接；复制题集保留来源并成为私有。
- 练习时不提前下发答案。提交后服务端判单选，简答标记待自评，不假装 AI 已精确判分。保存题目版本快照，作者改题不篡改历史作答。
- 练习进度浏览器保存，完成后结果在服务端记录；我的记录和错题入口真实可用。
- 复用 docx 导出题集。旧 /index /index2 入口转向新工作台。
- 可配置兼容 Chat Completions 的模型。密钥只存在服务端当前进程用户会话配置中，重启后需重新配置；支持环境默认。界面不得回显密钥。
- 基于粘贴资料的 AI 出题：后台任务、真实状态、结构化题目校验、精确重复去重、原文引用存在校验、结果导入编辑器后由用户保存。缺密钥时明确不可用。模型失败不能替换成样例。

## 分期边界

后续单独实现 PDF 文档索引和页码定位、语义去重与覆盖评测、诊断式教学 Agent、纠错协作。首版不提供假 Agent 对话、假掌握度、假社区数据。

## API 契约

所有 JSON 字段 camelCase；错误 `{error:string}`，更新冲突 409，未授权资源 404。写请求需 `X-Requested-With: ExamHub`，同源代理，不启用任意 CORS。前端另附 `X-Expected-User` 绑定当前页面身份；与实际 cookie 身份不符时返回 409 和 `code: session_changed`，阻止跨标签页切换账户后的错误归属。

`User={id,name,email:null|string}`。
`Question={id,type:'single'|'short',prompt,options:string[],answer:string,explanation,source:string,topic:string}`。single answer 是正确选项的完整字符串。
`SetSummary={id,title,description,topic,visibility:'private'|'unlisted'|'public',version:number,questionCount:number,author:string,ownerId:string,isOwner:boolean,bookmarked:boolean,updatedAt:string,sourceSetId:null|string}`。
`SetDetail=SetSummary & {questions:Question[]}`。只给 owner 的详情返回答案，其他用户详情去除 answer/explanation，source 可保留作者公开填写的文本。

- GET /api/session -> `{user:User}` 自动建立访客会话。
- POST /api/auth/register `{name,email,password}`，POST /api/auth/login `{email,password}` -> `{user}`；POST /api/auth/logout -> `{user}` 新访客。
- GET /api/sets?scope=mine|discover|saved&q=&topic= -> `{sets:SetSummary[]}`；mine 含自己题集，discover 仅 public。
- POST /api/sets `{title,description,topic,visibility,questions}` -> `{set:SetDetail}`。
- GET /api/sets/:id -> `{set:SetDetail}`。
- PUT /api/sets/:id `{version,title,description,topic,visibility,questions}` -> `{set}`；带原 version 乐观并发控制。
- DELETE /api/sets/:id -> `{ok:true}`。
- POST /api/sets/:id/fork -> `{set}`，副本私有，题目 ID 重新分配。
- POST /api/sets/:id/bookmark -> `{bookmarked:boolean}` 切换。
- GET /api/sets/:id/practice -> `{set:SetSummary,questions:Omit<Question,'answer'|'explanation'>[]}`。
- POST /api/sets/:id/attempts `{version,answers:Record<questionId,string>}` -> `{attempt:Attempt}`；版本不匹配 409。
- GET /api/attempts -> `{attempts:Attempt[]}`。
- `Attempt={id,setId,setTitle,version,createdAt,correct:number,total:number,results:Array<{questionId,prompt,type,options,answer,userAnswer,explanation,source,topic,correct:boolean|null}>}`。short correct=null，前端明确自评不计自动得分。
- GET /api/ai/config -> `{configured:boolean,baseUrl:string,model:string}`。
- PUT /api/ai/config `{baseUrl,model,apiKey}` -> 同 GET。空 apiKey 保留已设置密钥。
- POST /api/ai/jobs `{source,title,topic,count:number}` -> `{job:Job}`。
- GET /api/ai/jobs/:id -> `{job:Job}`；DELETE /api/ai/jobs/:id 取消 -> `{job}`。
- `Job={id,status:'queued'|'running'|'completed'|'failed'|'cancelled',error:string|null,questions:Question[],createdAt:string}`。

## 后端集成约定

Flask create_app(config=None)，config DATABASE 指向 SQLite。每请求 g.user 为 User 字典，后端 db.get_db() 返回带 Row 的连接。ai.py 由协调者单独实现，app factory 中 `from ai import register_ai; register_ai(app)`。支持 `cd backend && ../.venv/bin/python app.py`；unittest discovery 从 backend 运行。

## 验收

两客户端隔离；private/unlisted 不进入广场；不能篡改别人的题；练习响应无答案；提交快照不随改题改变；复制来源正确；坏输入不造成 500；模型错误可见；刷新数据保留；完整 pnpm build 通过；桌面和 390px 手机浏览器实测创建、分享、作答、记录与编辑路径。
