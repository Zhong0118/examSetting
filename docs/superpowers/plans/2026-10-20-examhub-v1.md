# ExamHub Workbench Implementation Plan

> **For agentic workers:** Use subagent-driven-development to implement disjoint backend and frontend tasks; coordinator owns AI service and integration.

**Goal:** 交付真实可用的题集工作台与创建分享练习闭环。
**Architecture:** Vue SPA + Flask API + SQLite 单机持久化，Vite 同源代理。界面及核心 API 并行开发，AI 模块独立集成。
**Tech Stack:** Vue 3, TypeScript, Vue Router, Flask, SQLite, Python unittest, Node test runner, browser verification. 首版共享会话直接使用 Vue 响应式状态，无需额外状态库。
**Spec:** `docs/superpowers/specs/2026-10-20-examhub-v1.md`

## Global Constraints

- 中文界面，白黑蓝色调，无 emoji，无伪造数据或 AI 输出。
- 后端源代码不含密钥，资源隔离在服务端实施。
- 数据与交互必须按规格 API 契约联调。
- 首版 SQLite 与文本资料是明确范围，不宣称已实现 PDF 或自主教学 Agent。
- 当前分支 codex/examhub-workbench，不提交或推送；保留已有调研文档。
